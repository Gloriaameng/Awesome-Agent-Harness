    Four architectures, four design questions

    Claude Code
    Claude Code integrates repository exploration, editing, commands, and delegated work into a coding workflow. It shows how context selection and action approval shape the path from a user goal to a tested artifact.
    Codex
    Codex connects model and tool events through an execution loop, persisted rollouts, and approval and sandbox controls. It makes the relationship between execution, recoverable state, and client interfaces central to architecture analysis.
    DeepSeek Harness
    DeepSeek Harness exposes runtime components through plugins, profiles, and patches. Typed tools, session events, and replaceable services make it a case for studying component boundaries and controlled runtime modification.
    OpenClaw
    OpenClaw coordinates messaging channels, persistent sessions, and scheduled work through a gateway. It extends the comparison to agents whose identity, state, and authority remain relevant across interactions and over time.

    Evaluation landscape

    Six areas of harness evaluation

    Six research questions organize the evaluation literature, connecting benchmark suites, evaluation methods, and the infrastructure needed to run them.

    Task environments such as OSWorld, WebArena, GAIA, and SWE-bench remain essential. They measure configured-system task performance; a harness-effect study adds controls that isolate runtime changes.

    Harness evolution

    How harnesses change through experience

    Harness evolution operates on different objects: reusable skills, executable runtime code, or the model and runtime together. The survey compares what changes, which feedback guides the change, and how improvements are evaluated.
